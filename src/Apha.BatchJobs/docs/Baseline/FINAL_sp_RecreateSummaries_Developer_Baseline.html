sp_RecreateSummaries

Main orchestration procedure.

Original SQL Code: Embedded
CREATE PROC [dbo].[sp_RecreateSummaries] @Month int AS
declare @periodLocked as smallint

EXECUTE sp_deleteFPSTotals
EXECUTE sp_createFPSTotals
EXECUTE sp_InsertMissingProjects
EXECUTE sp_deleteTimeCostCalcs
EXECUTE sp_CreateTimeCostCalcs
EXECUTE sp_DeleteProjectMonthCasework
EXECUTE sp_CreateProjectMonthCasework
EXECUTE sp_DeleteProjectMonthFinal
EXECUTE sp_deleteProjectMonth2
EXECUTE sp_qryJobMonth_Single
EXECUTE sp_DeleteProjectMonth3
EXECUTE sp_qryJobMonthCum
EXECUTE sp_qryJobMonth_Final @Month
EXECUTE usp_LogRecreateSummaries @Month

select @periodLocked=periodLocked
FROM tblPeriod
where endperiod=@month

if @periodLocked=0
begin
 EXECUTE usp_Refresh_Period_MO @month
 EXECUTE usp_Refresh_Period_psc @month
 EXECUTE usp_Refresh_Period_tcc @month
end
Logic Explanation for Developers
  • This is the main orchestration procedure for rebuilding FPS summary data for a supplied @Month.
  • It first deletes and recreates FPSYearTotals.
  • It ensures missing project/month rows exist by calling sp_InsertMissingProjects.
  • It rebuilds TimeCostCalcs, ProjectMonthCasework, ProjectMonth2, ProjectMonth3, and finally ProjectMonthFinal.
  • It logs the run using usp_LogRecreateSummaries.
  • It checks tblPeriod.PeriodLocked for the supplied month. If the period is not locked, it refreshes period-level Monthly Output, Project Subcontract, and Time Cost Calc tables.
Developer Note: Preserve the exact execution order. Later steps depend on outputs created by earlier steps.

sp_InsertMissingProjects

Ensures ProjectMonth rows exist for all projects/months.

Original SQL Code: Embedded
CREATE proc [dbo].[sp_InsertMissingProjects] AS  DECLARE @Month int  DECLARE @Message varchar(10)  SELECT @month = 1  WHILE (@month < 13)   BEGIN   INSERT INTO ProjectMonth (Project, MonthNo)   SELECT DISTINCT tlkpProject.ParentProject,     @month AS MonthNo   FROM   tlkpProject LEFT JOIN ProjectMonth ON      tlkpProject.ParentProject = ProjectMonth.Project     AND @month = ProjectMonth.MonthNo    WHERE ((ProjectMonth.Project IS NULL))   ORDER BY ParentProject   SELECT @month = @month + 1   IF @month = 13    BREAK   ELSE    CONTINUE  END
Logic Explanation for Developers
  • Loops month numbers from 1 to 12.
  • For each month, inserts missing ProjectMonth rows for projects in tlkpProject.
  • A row is inserted only when that project/month combination does not already exist.
  • This creates the base project-month grid used by later monthly summary logic.
Developer Note: This procedure is not calculating financial values; it is ensuring baseline rows exist for every project/month.

sp_Get_SP_No

Nested stored procedure called by usp_LogRecreateSummaries to derive user id from SYSTEM_USER.

Original SQL Code: Embedded
CREATE PROCEDURE [dbo].[sp_Get_SP_No]
@Mno varchar(20) OUTPUT
AS
SELECT @MNo = SUBSTRING(SYSTEM_USER, CHARINDEX('\', SYSTEM_USER) + 1, 20)
GO
Logic Explanation for Developers
  • Extracts the Windows/user login name from SYSTEM_USER.
