Application Code KB for ReArchitect Conversion

Purpose
Convert legacy sql stored procedures into dotnet batch code with behavior parity.

Scope
Scheduled and Adhoc procedure conversion.
Use approved foundation structure from ReImagine output.

Target Outcome
Compile ready procedure conversion modules.
Preserve existing behavior first then optimize later.

Conversion Rules
Maintain input output behavior parity
Preserve null handling and default behavior
Preserve transaction intent where defined
Preserve procedure execution order for orchestrators
Map dynamic sql safely and explicitly
Use set based operations where possible

Definition of Done
Generated code compiles
Procedure mapping report is complete
Critical parity tests pass
No placeholder implementation methods
