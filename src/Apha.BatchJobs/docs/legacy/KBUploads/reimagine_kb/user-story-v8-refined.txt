As a platform developer I want a complete runnable dotnet 8 backend solution called AphaBatchJobs so that scheduled and adhoc PostgreSQL batch operations can be hosted and deployed to AWS ECS Fargate via Docker.

Background

The Apha platform runs batch operations against a PostgreSQL database. Two categories exist. Scheduled jobs run on a cron schedule triggered by a CLI argument. Adhoc jobs run on demand triggered by a different CLI argument with a job name parameter. This story produces only the foundation layer. No stored procedures are converted here. All future job implementations plug into this foundation.

Solution Structure

The solution file is AphaBatchJobs.sln and it references four projects. The four projects are AphaBatchJobs.Host, AphaBatchJobs.Application, AphaBatchJobs.Core, and AphaBatchJobs.Infrastructure.

Project AphaBatchJobs.Host

The project file AphaBatchJobs.Host.csproj targets net8.0 with OutputType Exe and references AphaBatchJobs.Application and AphaBatchJobs.Infrastructure.

NuGet packages for Host:
- Microsoft.Extensions.Hosting version 8.0.1
- Microsoft.Extensions.Logging.Console version 8.0.0
- Serilog.AspNetCore version 8.0.3
- Serilog.Sinks.Console version 6.0.0
- Serilog.Enrichers.Environment version 3.0.1
- CommandLineParser version 2.9.1

Program.cs is an async entry point. It creates a Generic Host using Host.CreateDefaultBuilder passing args. In ConfigureServices it calls a static AddBatchJobsInfrastructure extension method passing the configuration. It reads args to determine trigger mode. If args is null or length zero it logs an error and returns 1. If args contains --scheduled it resolves IJobRunnerService, calls RunScheduledAsync with CancellationToken.None, and returns the int result. If args contains --adhoc and a second argument it reads the job name from the second argument, resolves IJobRunnerService, calls RunAdhocAsync with the job name and CancellationToken.None, and returns the int result. If args contains --help it prints usage and returns 0. All unhandled exceptions are caught, logged with Log.Fatal, and environmental cleanup is done via await Log.CloseAndFlushAsync before exiting with code 1.

appsettings.json contains a ConnectionStrings section with DefaultConnection set to empty string. It contains a Serilog section with MinimumLevel.Default set to Information. It contains a Scheduler section with TimeoutSeconds set to 30.

appsettings.Development.json overrides the DefaultConnection with Host=localhost;Database=AphaBatchJobs;Username=postgres;Password=postgres as a PostgreSQL connection string.

Dockerfile is a multi-stage build using mcr.microsoft.com/dotnet/sdk:8.0 for the build stage and mcr.microsoft.com/dotnet/runtime:8.0 for the runtime stage. It copies the solution file and all project folders into /src, runs dotnet restore for AphaBatchJobs.Host, then runs dotnet publish on AphaBatchJobs.Host -c Release -o /app/publish. The runtime stage sets ENTRYPOINT to invoke dotnet AphaBatchJobs.Host.dll.

Project AphaBatchJobs.Application

The project file AphaBatchJobs.Application.csproj targets net8.0 and references AphaBatchJobs.Core.

NuGet packages for Application:
- Microsoft.Extensions.DependencyInjection.Abstractions version 8.0.0
- Microsoft.Extensions.Logging.Abstractions version 8.0.0

IJobRunnerService declares async Task of int RunScheduledAsync with CancellationToken parameter and async Task of int RunAdhocAsync with string jobName and CancellationToken parameters.

JobRunnerService implements IJobRunnerService. Its constructor receives IEnumerable of IScheduledJob, IEnumerable of IAdhocJob, ILogger of JobRunnerService, and ICorrelationIdService via dependency injection. RunScheduledAsync creates a new JobExecutionContext with correlation id, JobType set to Scheduled, job name empty, and current DateTimeOffset. It iterates through all registered IScheduledJob implementations calling ExecuteAsync on each with the context and cancellation token. It returns an int exit code based on overall success. RunAdhocAsync finds the IAdhocJob in the collection whose JobName property matches the requested job name parameter. If no match found it returns 1. If found it creates a JobExecutionContext with the matched job name, a new correlation id, JobType set to Adhoc, and current DateTimeOffset. It calls ExecuteAsync on the matched job and returns the exit code.

Project AphaBatchJobs.Core

The project file AphaBatchJobs.Core.csproj targets net8.0 with no external NuGet package dependencies.

IScheduledJob declares async Task of JobExecutionResult ExecuteAsync with JobExecutionContext and CancellationToken parameters.

IAdhocJob declares async Task of JobExecutionResult ExecuteAsync with JobExecutionContext and CancellationToken parameters and a string property JobName.

ICorrelationIdService declares string NewId that returns a unique correlation identifier.

JobExecutionResult is a record with string Status, string Message, and int ExitCode properties.

JobExecutionContext is a record with string JobName, string CorrelationId, JobType TriggerType, and DateTimeOffset StartedAt properties.

JobExecutionStatus is an enum with Success equal to 0, Failed equal to 1, PartialSuccess equal to 2, and Skipped equal to 3.

JobType is an enum with values Scheduled and Adhoc.

Project AphaBatchJobs.Infrastructure

The project file AphaBatchJobs.Infrastructure.csproj targets net8.0 and references AphaBatchJobs.Core and AphaBatchJobs.Application.

NuGet packages for Infrastructure:
- Npgsql.EntityFrameworkCore.PostgreSQL version 8.0.10
- Microsoft.EntityFrameworkCore version 8.0.0
- Microsoft.EntityFrameworkCore.Relational version 8.0.0
- Microsoft.Extensions.Configuration version 8.0.0
- Microsoft.Extensions.Configuration.Binder version 8.0.0
- Microsoft.Extensions.DependencyInjection version 8.0.0
- Microsoft.Extensions.Hosting version 8.0.1
- Quartz version 3.13.1
- Quartz.Extensions.DependencyInjection version 3.13.1

ServiceCollectionExtensions.cs contains a static class with a static AddBatchJobsInfrastructure extension method on IServiceCollection accepting IConfiguration. The method validates services and configuration are not null using ArgumentNullException.ThrowIfNull. It binds DatabaseOptions from the configuration section DatabaseOptions. It binds JobOptions from the configuration section JobOptions. It adds a DbContext of type AphaDbContext using AddDbContext with UseNpgsql. The NpgsqlDbContextOptionsBuilder calls EnableRetryOnFailure with max retry count 3 and max retry delay 5 seconds. It sets command timeout from configuration section DatabaseOptions.TimeoutSeconds if present. It registers CorrelationIdService as singleton implementing ICorrelationIdService with a static NewId method that returns Guid.NewGuid().ToString(). It calls AddQuartz passing a configuration action. The configuration action sets SchedulerId to AphaBatchJobsScheduler and SchedulerName to Apha Batch Jobs Scheduler. It calls UseInMemoryStore. It calls UseDefaultThreadPool with MaxConcurrency 10. It sets InterruptJobsOnShutdown to true. It calls AddQuartzHostedService passing options to set WaitForJobsToComplete to true. The method returns services for chaining.

DatabaseOptions.cs is a sealed class with string property DefaultConnection, int property TimeoutSeconds with a get and set, and int property MaxRetries with a get and set.

JobOptions.cs is a sealed class with int properties TimeoutSeconds and MaxRetries both with get and set.

CorrelationIdService.cs is a sealed class implementing ICorrelationIdService. The NewId property returns Guid.NewGuid().ToString().

AphaDbContext.cs extends DbContext. Its constructor takes DbContextOptions of AphaDbContext type and passes to base. OnModelCreating calls base.OnModelCreating with the model builder.
