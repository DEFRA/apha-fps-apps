3

Total Estimated Effort

10-15 hours over 5 days (assuming 2-3 hours per day allocation)

Parallel activities where possible can reduce total duration. For example, GitHub repo and AWS infrastructure setup can happen simultaneously.

☁️ Phase 2: AWS Infrastructure (Day 2)

Objective: Set up AWS ECR and OIDC authentication

AWS Console → ECR
Repository name: apha/batchjobs
Scan on push: Enable (ECR Basic)
Encryption: Use AWS managed key
KMS encryption: Not required (default is fine)
ECR Repository → Lifecycle policies → Create rule
Rule 1: Keep latest 20 images, expire others
Rule 2: Expire untagged images after 7 days
(See DevOps specification for JSON policy)
AWS Console → IAM → Identity providers
Check if token.actions.githubusercontent.com exists
If not, create:
  • Provider type: OpenID Connect
  • Provider URL: https://token.actions.githubusercontent.com
  • Audience: sts.amazonaws.com
AWS Console → IAM → Roles → Create role
Type: Web identity (OIDC)
Provider: token.actions.githubusercontent.com
Audience: sts.amazonaws.com
Subject claim filter: repo:DEFRA/apha-batch-jobs:*
Role name: apha-batch-jobs-github-actions
Create inline policy or attach managed policy
Required permissions:
  • ecr:GetAuthorizationToken
  • ecr:BatchCheckLayerAvailability
  • ecr:GetDownloadUrlForLayer
  • ecr:BatchGetImage
  • ecr:PutImage
  • ecr:InitiateLayerUpload
  • ecr:UploadLayerPart
  • ecr:CompleteLayerUpload
Resource: arn:aws:ecr:*:ACCOUNT_ID:repository/apha/batchjobs
Record the following (needed for Phase 3):
  • ECR Repository URI: <ACCOUNT_ID>.dkr.ecr.<REGION>.amazonaws.com/apha/batchjobs
  • IAM Role ARN: arn:aws:iam::<ACCOUNT_ID>:role/apha-batch-jobs-github-actions
  • AWS Region: <REGION>
Use AWS CLI to test role assumption (optional but recommended)
aws sts assume-role-with-web-identity \ --role-arn arn:aws:iam::ACCOUNT_ID:role/apha-batch-jobs-github-actions \ --role-session-name test-session \ --web-identity-token $GITHUB_TOKEN \ --duration-seconds 900

🔧 Troubleshooting Guide

Common Issues and Solutions

❌ Workflow fails: "OIDC token validation failed"

Cause: GitHub OIDC provider not configured or role trust relationship incorrect
Solution:
  1. Verify OIDC provider exists: AWS IAM → Identity providers
  2. Check role trust relationship includes GitHub org and repo
  3. Verify subject claim filter: repo:DEFRA/apha-batch-jobs:*
  4. Re-run workflow after fix

❌ ECR push fails: "denied: User is not authorized"

Cause: IAM role lacks ECR permissions
Solution:
  1. Verify role policy includes ecr:PutImage
  2. Check resource ARN matches ECR repository
  3. Ensure role is attached to GitHub OIDC provider
  4. Test role with AWS CLI: aws sts get-caller-identity

❌ Tests fail: "database connection timeout"

Cause: PostgreSQL service not starting or connection string incorrect
Solution:
  1. Check workflow PostgreSQL service definition
  2. Verify connection string environment variable: ConnectionStrings__BatchJobsConnectionString
  3. Confirm port 5432 accessible to runner
  4. Check test log output for specific error

❌ Image build fails: "layer already exists"

Cause: Docker layer caching issue or multiple pushes of same commit
Solution:
  1. Clear Docker build cache: docker system prune -a
  2. Update workflow to use unique image tags (commit SHA)
  3. Consider ECR lifecycle policy for cleanup

❌ Workflow timeout: "runner is timed out"

Cause: Long-running tests or build operations exceeding runner limits
Solution:
  1. Check test duration — optimize slow tests
  2. Increase workflow timeout if appropriate
  3. Consider splitting into multiple parallel jobs
  4. Profile build time: dotnet build --verbosity=diagnostic
