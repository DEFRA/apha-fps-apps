State Transition Flow

User clicks Trigger │ ▼ PACT API (HTTP 202) ──saves──▶ PACT Trigger Store (IMemoryCache) │ └─ jobExecutionId, acceptedAtUtc, workerLaunchHint │ ▼ (UI starts polling /status) ┌─ Startup Watchdog Phase ────────────────────────────────────────┐ │ PACT resolves from trigger store (no fps.job_queue row yet) │ │ │ │ projectedState = TriggerAccepted (event sent, no ack yet) │ │ projectedState = WorkerProcessStarted (local proc launched) │ │ projectedState = StartFailedTimeout ──────────────────────────┼──▶ ❌ STOP (SLA exceeded) └─────────────────────────────────────────────────────────────────┘ │ (worker starts, writes row to fps.job_queue) │ ▼ ┌─ Persistent DB Phase (fps.job_queue) ───────────────────────────┐ │ │ │ Pending ──▶ Running ──▶ Completed ✅ │ │ └──▶ Failed ──▶ Retry ──▶ Pending… │ │ └──▶ Cancelled ✅ │ │ Skipped ✅ (concurrent detection at trigger time) │ └─────────────────────────────────────────────────────────────────┘ DB Table: fps.job_queue ├─ job_execution_id (UUID, correlation key, matches PACT trigger store) ├─ job_name ├─ current_state (Pending | Running | Completed | Failed | Retry | Cancelled | Skipped) ├─ started_at ├─ completed_at ├─ requested_by └─ error_message Watchdog Correlation: /status?jobExecutionId={uuid} → PACT looks up trigger store first (no acceptedAtUtc required from client) → If no DB row + store hit → returns startupWatchdog projection → If DB row found → returns lastExecution (authoritative)
