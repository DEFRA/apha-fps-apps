Re-Architect Wave 1: Scheduled Job Orchestrator (sp_LoadFromFPS)

Current State

The AphaBatchJobs foundation has been established with v0.1.0-foundation targeting net8.0 on PostgreSQL and AWS ECS Fargate. The foundation provides four projects (Host, Application, Core, Infrastructure), CLI execution modes (--scheduled and --adhoc), Quartz scheduling, and dependency injection wiring. No stored procedures have been converted to C# yet.

Objective

Convert the sp_LoadFromFPS master orchestrator procedure and its dependency chain from SQL Server stored procedures to a composable C# implementation that runs within the foundation's scheduled job execution framework.

Scope

This wave focuses on the sp_LoadFromFPS orchestrator, which is the master procedure controlling all scheduled data loading operations. The procedure orchestrates five dependent stored procedures:

1. sp_DeleteFPSJobAdhocResults — Clears previous adhoc results
2. sp_LoadFPSTotals — Loads aggregated cost and income totals
3. sp_RecreateYearData — Recreates current year financial data
4. sp_LoadPreviousYearData — Loads prior year data for comparison
5. sp_RecreateArchives — Archives old records for historical tracking

Execution Order

The orchestrator must execute these procedures in the following sequence:

Step 1: Execute sp_DeleteFPSJobAdhocResults
- Clears all adhoc results from the previous run
- No parameters required
- Must complete before any data loading

Step 2: Execute sp_LoadFPSTotals
- Depends on: Step 1 must be complete
- Loads summary totals for all projects
- Depends on tables: tblProject summary and cost tracking views
- Result: Populates FPSYearTotals table

Step 3: Execute sp_RecreateYearData
- Depends on: Step 2 must be complete
- Recreates current fiscal year project financial data
- Depends on: FPSYearTotals (populated by Step 2)
- Result: Recreates year_data tables with current financials

Step 4: Execute sp_LoadPreviousYearData
- Depends on: Step 3 must be complete
- Loads previous fiscal year data for comparison and reporting
- Depends on: Archive tables and previous year snapshots
- Result: Populates previous_year_data for trending

Step 5: Execute sp_RecreateArchives
- Depends on: Step 4 must be complete and only executed if all prior steps succeeded
- Archives completed records to historical storage
- Cleanup: Removes old archived records older than 24 months
- Result: Moves completed records to archive tables

Overall Execution Rules

- If any step fails, immediately halt orchestration and log error
- Return exit code 1 if any step fails
- Return exit code 0 only if all five steps complete successfully
- Each step must validate its results before proceeding to the next step
- Timeout: each step must complete within 300 seconds
- If a step exceeds timeout, cancel execution and return exit code 2

Output Specification

Create a new IScheduledJob implementation called ScheduledLoadFromFpsJob that:

1. Implements IScheduledJob interface from Core project
2. Registers as a singleton in Infrastructure DI wiring
3. Executes the five stored procedures in order via Npgsql/EntityFrameworkCore command interface
4. Logs each step execution: start, step name, parameters (if any), duration, and result
5. Catches exceptions per-step, logs them with correlation ID, and halts orchestration
6. Returns JobExecutionResult with:
   - Status: "Success" if all 5 steps complete, "Failed" if any step fails, "Timeout" if step exceeds 300s
   - Message: human-readable summary (e.g., "All 5 steps completed successfully" or "Failed at step 3: sp_RecreateYearData")
   - ExitCode: 0 for success, 1 for failure, 2 for timeout

Code Organization

- Create new file: AphaBatchJobs.Application/Scheduled/ScheduledLoadFromFpsJob.cs
- Inject: ILogger, IDbConnection (or DbContext), ICorrelationIdService
- Method signature: async Task<JobExecutionResult> ExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken)
- Each step should be a private async method that returns bool (success/failure)

Logging Detail

All logging through ILogger<ScheduledLoadFromFpsJob> at Information level for step entry/exit and Warning level for retries or non-fatal issues. At Error level for step failures with full exception details.

Acceptance

- Solution compiles without errors: dotnet build AphaBatchJobs.sln
- ScheduledLoadFromFpsJob is correctly registered in DI and discoverable via IEnumerable<IScheduledJob>
- Running with --scheduled flag executes the job and all 5 stored procedure steps in correct order
- Logs show clear step progression and timings
- Exit codes 0, 1, and 2 are returned appropriately based on execution result
- No TODO comments in generated code
- No placeholder or stub methods

```sql
SET ANSI_NULLS ON

GO
SET QUOTED_IDENTIFIER ON

GO
CREATE procEDURE [dbo].[sp_createFPSTotals] AS
INSERT INTO FPSYearTotals
SELECT DISTINCT 
	tlkpProject.ParentProject,
	tlkpProject.Program, 
	
	CASE
		WHEN qryTotalAdditionalCosts.TotalAdditionalCosts IS NULL THEN
			0
		ELSE
			qryTotalAdditionalCosts.TotalAdditionalCosts
		END AS TotalAdditionalCosts, 
	CASE
		WHEN qryTotalAnimalCosts.TotalAnimalCosts IS NULL THEN
			0
		ELSE
			qryTotalAnimalCosts.TotalAnimalCosts
		END AS TotalAnimalCosts, 
	CASE
		WHEN qryTotalStaffCosts.TotalStaffCosts IS NULL THEN
			0
		ELSE
			qryTotalStaffCosts.TotalStaffCosts
		END AS TotalStaffCosts, 
	CASE
		WHEN qryTotalTestCosts.TotalTestCosts IS NULL THEN
			0
		ELSE
			qryTotalTestCosts.TotalTestCosts
		END AS TotalTestCosts, 
	CASE
		WHEN qryTotalAdditionalCosts.TotalAdditionalCosts IS NULL THEN
			0
		ELSE
			qryTotalAdditionalCosts.TotalAdditionalCosts
		END + 
	CASE
		WHEN qryTotalAnimalCosts.TotalAnimalCosts IS NULL THEN
			0
		ELSE
			qryTotalAnimalCosts.TotalAnimalCosts
		END  + 
	CASE
		WHEN qryTotalStaffCosts.TotalStaffCosts IS NULL THEN
			0
		ELSE
			qryTotalStaffCosts.TotalStaffCosts
		END +
	CASE
		WHEN qryTotalTestCosts.TotalTestCosts IS NULL THEN
			0
		ELSE
			qryTotalTestCosts.TotalTestCosts
		END +
CASE
		WHEN tlkpProject.PlanCaseworkDebit  IS NULL THEN
			0
		ELSE
 			tlkpProject.PlanCaseworkDebit 
		END AS TotalCosts,
	tlkpProject.CustIncome, 
	tlkpProject.TransferIncome, 
	custincome+Transferincome AS TotalIncome, 
	tlkpProject.Budget_CVL,
	tlkpProject.Profit as RequiredProfit, 
	tlkpProject.Manager, 
	tlkpProject.Customer, 
	tlkpProject.ProjectStatus, 
	Case 
		WHEN tlkpProject.PVSIncome  IS NULL THEN
			0
		ELSE
			tlkpProject.PVSIncome 
		END AS PVSIncome,
	CASE
		WHEN tlkpProject.PlanCaseworkDebit  IS NULL THEN
			0
		ELSE
 			tlkpProject.PlanCaseworkDebit 
		END AS PlanCaseworkDebit,

	CASE
		WHEN qryTotalStaffCosts.TotalPayCosts IS NULL THEN
			0
		ELSE
			qryTotalStaffCosts.TotalPayCosts
		END AS TotalPayCosts

FROM (((tlkpProject 
LEFT JOIN qryTotalAdditionalCosts ON tlkpProject.ParentProject = qryTotalAdditionalCosts.JobCode) 
LEFT JOIN qryTotalAnimalCosts ON tlkpProject.ParentProject = qryTotalAnimalCosts.JobCode) 
LEFT JOIN qryTotalStaffCosts ON tlkpProject.ParentProject = qryTotalStaffCosts.Jobcode) 
LEFT JOIN qryTotalTestCosts ON tlkpProject.ParentProject = qryTotalTestCosts.JobCode
```

### sp_LoadFromFPS
```sql
CREATE PROCEDURE [dbo].[sp_LoadFromFPS]
AS
BEGIN
declare @cFPSVersion varchar(20)
declare @FPSYear int
declare @RC int
Declare @sql VARCHAR(50)

SET @FPSYear=DatePart(yyyy,Getdate())-1
SET @cFPSVersion='FPS'+cast(@FPSYear as varchar(4))

if (SELECT Count(*) FROM master.dbo.sysdatabases where name =@cFPSVersion)>0
begin
set @sql = @cFPSVersion +'.dbo.sp_deleteFPSTotals'
Exec @sql
set @sql = @cFPSVersion +'.dbo.sp_createFPSTotals'
Exec @sql    
Exec sp_DeleteYearsFPSData @cFPSVersion, @FPSYear
Exec sp_AddYearsFPSData @cFPSVersion, @FPSYear
end

if DATEPART(month, GETDATE()) >4
begin
SET @FPSYear=DatePart(yyyy,Getdate())
SET @cFPSVersion='FPS'+cast(@FPSYear as varchar(4))

if (SELECT Count(*) FROM master.dbo.sysdatabases where name =@cFPSVersion)>0
begin
set @sql = @cFPSVersion +'.dbo.sp_deleteFPSTotals'
Exec @sql
set @sql = @cFPSVersion +'.dbo.sp_createFPSTotals'
Exec @sql   
Exec sp_DeleteYearsFPSData @cFPSVersion, @FPSYear
Exec sp_AddYearsFPSData @cFPSVersion, @FPSYear
end
end
else
begin
SET @FPSYear=DatePart(yyyy,Getdate())
SET @cFPSVersion='FPS'+cast(@FPSYear as varchar(4))

if (SELECT Count(*) FROM Master.dbo.sysdatabases where name =@cFPSVersion)>0
begin  
DELETE from MY_tlkpProject_all WHERE Year=@FPSYear
Exec sp_AddMY_tlkpProject_All @cFPSVersion, @FPSYear
end
end
END
```

### sp_AddMY_Staff
```sql
CREATE PROCEDURE [dbo].[sp_AddMY_Staff]
(@cFPSVersion as VarChar(20), @vcFPSYear as int)
AS
BEGIN
declare @sqlstr as varchar(2000)
set @sqlstr ='INSERT INTO MY_Staff(
[Year], [StaffID], [Name], [WorkGroupGrade], [Title],
[PersonStatus], [PersonClass], [HrsPaid], [Leave],
[SickSpecial], [HrsAvail]
)
SELECT ' + Cast(@vcFPSYear as VarChar(4)) +' as year,
WGE.PactID as [StaffID],
ISNULL(E.Lastname,'''') + '', '' + ISNULL(E.firstname,'''') as Name,
WGE.[WorkGroupGrade], E.[Title], WGE.[PersonStatus], WGE.[PersonClass],
WGE.[HrsPaid], WGE.[Leave], WGE.[SickSpecial], WGE.[HrsAvail]
FROM '+ @cFPSVersion + '.dbo.tblWGEmployee as WGE, '+ @cFPSVersion + '.dbo.tblEmployee as E
WHERE WGE.SPNumber = E.SPNumber AND
WGE.WorkGroupGrade IN
(
SELECT WGG.WGrade from '+ @cFPSVersion + '.dbo.WorkgroupGrade AS WGG
WHERE WGG.WorkGroup IN
(
SELECT WG.WorkGroup FROM '+ @cFPSVersion + '.dbo.WorkGroup AS WG
WHERE WG.ProfitCentre IN
(
SELECT UPC.ProfitCentre FROM '+ @cFPSVersion + '.dbo.tblUser_ProfitCentre AS UPC
WHERE UPC.[User_ID] IN
(
SELECT U.[User_ID] FROM '+ @cFPSVersion + '.dbo.tblUsers AS U WHERE U.UserName=USER_NAME(1)
)
)
)
)'

exec(@sqlstr)
END
```

CREATE PROCEDURE [dbo].[spSendProjectManagerEditEmail]
AS
BEGIN
CREATE TABLE #EmailList(
[ID] [int] IDENTITY(1,1) NOT NULL,
[mNumber] [varchar](50) NULL,
[Name] [varchar](50) NULL,
[Email] [varchar](200) NULL,
CONSTRAINT [PK_EmailList] PRIMARY KEY CLUSTERED ([ID] ASC)
)

INSERT INTO #EmailList(mNumber, Name, Email)
SELECT MNumber, ProjectManager, Email
FROM vProjectReports_PMMilestoneMail
WHERE Disable=0 and EMAIL is not null
GROUP BY MNumber, ProjectManager, Email

DECLARE @i as int
DECLARE @mNumber as VARCHAR(50)
DECLARE @Name as VARCHAR(50)
DECLARE @Email as VARCHAR(200)
SET @i=0

SELECT TOP 1 @mNumber=Mnumber, @Name=Name, @Email=Email
FROM #EmailList
ORDER BY ID

WHILE @@ROWCOUNT>0
BEGIN
EXEC [dbo].[spSendProjectEditMilestoneLink]
@mNumber = @mNumber,
@manager = @Name,
@Email = @Email
SET @i=@i+1
SELECT TOP 1 @mNumber=Mnumber, @Name=Name, @Email=Email
FROM #EmailList
WHERE ID>@i
ORDER BY ID
END

Drop table #EmailList

set @Email=(select setting from [tbl Settings] where id='CAPSMailbox')

exec msdb.dbo.sp_send_dbmail   
@profile_name = 'sqlmail',
@recipients = @Email,
@subject = 'PIMS Monthly Milestone Edit Links',
@body = 'The project managers milestone edit links have been mailed out.<br><br>
Please do not reply to this email.  If you are having problems please contact the helpdesk.',
@body_format = 'HTML'
END
