Application Code KB for ReImagine Foundation

Purpose
Define target foundation for batch jobs in alignment with existing solution conventions.

Scope
Scheduled and Adhoc batch host foundation only.
No procedure level conversion in this KB.

Target Outcome
Generate compile ready foundation skeleton.
Follow existing layered architecture and naming standards.
Keep orchestration in host and business logic in services.

Required Foundation Components
Program host bootstrap
Dependency injection extension setup
Configuration and options setup
Logging setup with correlation id
Error handling and exit code pattern
Scheduler and cli trigger contracts
Base job interfaces and job contracts
Docker baseline and runtime configuration template

Architecture Rules
Use clean layered architecture
Use interface based design
Use scoped lifetime for services repositories and db context
Keep infra concerns out of application orchestration layer
Avoid direct db context usage in orchestrator

Naming and Structure
Use Apha BatchJobs naming pattern
Use folder structure aligned to existing solutions
Use single responsibility per service class

Definition of Done
Code compiles
Project structure is complete
Host starts with valid config
Logs are structured
No placeholder only methods
